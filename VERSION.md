# Version

**Current Version:** 0.1.0

## Versioning

CodeAtlas uses semantic versioning in the `MAJOR.MINOR.PATCH` format.

- **MAJOR** — A breaking change that significantly changes existing behavior or compatibility.
- **MINOR** — A new feature or meaningful addition that does not break existing functionality.
- **PATCH** — A bug fix, correction, or small internal change that does not introduce a new feature.

Version `0.1.0` marks the beginning of formal version tracking for CodeAtlas.

Changes made before this version were not tracked using a formal versioning system.
